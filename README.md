# AI SaaS Churn Prediction

A full-stack machine learning app that predicts customer churn using:
- FastAPI backend
- Random Forest ML model
- Vite + React frontend

## Features
- Predict churn in real-time
- Clean UI
- API integration with FastAPI
- Deployable to Render / Vercel

## How to Run

### Backend
cd backend
uvicorn app:app --reload

### Frontend
cd frontend
npm install
npm run dev
